Run from the site checkout: `node model-source/build-details.mjs` then `node model-source/export-interiors.mjs`. The source hull is the original dimensioned reconstruction before print engravings. Other hulls use their existing STL geometry. Three.js is r180 (MIT; see dist/vendor/THREE-LICENSE.txt). The bundled Helvetiker font retains its MAGENTA permission notice in the font JSON and dist/vendor/HELVETIKER-LICENSE.txt. Display meshes are Z-up, forward-negative-Y, in approximate metres. These generators do not alter fabrication STL files.
